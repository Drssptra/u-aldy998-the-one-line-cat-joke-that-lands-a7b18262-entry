A tiny Node program that prints one original one-line cat joke — a cat walks across its owner's keyboard during a job interview, and the punchline lands on both of them working from home — and writes the same line to `entry.txt`. The joke fits the brief: a setup and a turn in a single short line, a fresh angle on the classic cat-on-keyboard chaos, and a punchline a person would actually retell to a friend the same day.

## Run it

```sh
node main.ts
```
